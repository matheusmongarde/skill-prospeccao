## Como Plugar na Sua Operação em 3 Minutos

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/matheusmongarde/skill-prospeccao.git
   ```
2. **Copie a pasta `skills/`** para o diretório de skills do seu agente ou carregue os arquivos `SKILL.md` no prompt de sistema / contexto do projeto.
3. **Preencha o bloco de configuração** dentro de [`skills/06-lista-negra-e-governanca/SKILL.md`](skills/06-lista-negra-e-governanca/SKILL.md) com a sua oferta, ticket médio, canais ativos, nicho-alvo, região bloqueada e teto diário.
4. **Rode com governança:** o agente já nasce instruído a varrer jargões proibidos, checar lista negra antes de cada envio, nunca vender na primeira mensagem e parar imediatamente no primeiro "não".

---

## Regras Inegociáveis de Operação

1. **Proibido parecer robô:** zero jargão de marketing, zero textão na abertura, zero travessão artificial e zero bajulação.
2. **Zero venda no primeiro toque:** a primeira mensagem abre conversa com base em um fato público real; oferta só entra depois que o lead responde e confirma a dor.
3. **Lista negra é lei:** pediu para sair ou disse não, bloqueio imediato e permanente em todos os canais.
4. **Melhore após cada perda:** toda conversa perdida gera revisão de causa raiz para ajustar a abordagem antes da próxima leva.
